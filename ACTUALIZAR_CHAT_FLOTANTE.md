# Versión 1.2: chat flotante

1. Conserva el proyecto y su backend/.env.
2. Copia la carpeta extension de esta actualización sobre la carpeta extension que ya tienes cargada. Para conservar las fuentes nuevas, copia también apps/gmail y apps/outlook.
3. Abre la página de extensiones del navegador y pulsa Recargar en EmailAgent. No necesitas desinstalarla.
4. Recarga las pestañas de Gmail y Outlook para quitar el botón anterior y cargar la burbuja nueva.
5. Arrastra la bolita azul y pulsa sobre ella: se abre directamente el chat flotante de esa plataforma.
6. Arrastra la cabecera para mover la ventana; arrastra la esquina inferior derecha para cambiar el tamaño.
7. Pulsa − para minimizar. La conversación permanece mientras no recargues ni cierres esa página.

El icono de la barra abre o minimiza esa misma ventana. El engranaje abre las opciones. Las pestañas del chat permiten acceder a Correo, Acciones, Historial y Ajustes.

No cambia la IA compartida, las claves ni la base de datos. Conserva la recuperación de sesión de Gmail de la versión 1.1. Las autorizaciones pueden requerir confirmación de Google/Microsoft después de una actualización.

Las interfaces compilan y los scripts tienen sintaxis válida. Falta comprobar el arrastre, la inserción en el sitio y las autorizaciones en el navegador real.
